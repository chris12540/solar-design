How to model

Build a test roof

  1. Draw: Start a New example. Open Roof and choose Pitched roof, Flat roof, or Roof face. Click corners, then close on the first point. Select a whole rectangular roof to use Roof starter for Hip, Gable, or Shed; set pitch, footprint width/depth and direction before adding details.
  2. Edit: Double-click a SmartRoof to edit its roof lines. Select an edge for Length or Add corner at midpoint; drag the new corner into place. Select a corner for Angle and Remove corner. Select an independent roof face to drag its outline or change height and pitch.
  3. Add details: While editing a SmartRoof, use the bottom toolbar for dormers and folds. Escape leaves the tool.
  4. Move: Leave roof editing, select the whole roof, choose Move, then drag inside a roof face. Escape finishes Move.
  5. Keep your case: Save locally keeps a named checkpoint. Export test case downloads a file. Tab drafts help recover refreshes; they are not file backups.

Explode replaces a SmartRoof and its detail controls with independent faces. Generated walls can change. Export the original first if you need both versions.
