# AHJ registry and boundary sources

The registry snapshot is the user's 28-row Maricopa County, Arizona D1 schema. It is stored locally in `backend/data/ahj_registry.json`; every row remains `draft` with a null `boundary_ref`. `backend.ahj.registry(c)` returns that snapshot without connecting to or writing to D1, along with the SHA-256 of the exact registry file. Every assignment source carries that registry hash. Geometry-derived assignments also carry the boundary artifact hash and snapshot date; manual overrides carry only the registry hash so their provenance does not imply a boundary match.

The checked-in `backend/data/ahj_boundaries.geojson` is a WGS84 snapshot collected on 2026-10-13. It contains 24 city/town polygons selected from Arizona's statewide Incorporated Places Boundaries layer and three American Indian reservation polygons selected from the Census Bureau's TIGERweb layer. Features retain the registry `ahj_id`; registry status stays independent from source availability. Retrieval dates, raw response SHA-256 hashes, and the checked-in artifact hash are recorded in `backend/data/ahj_boundaries.meta.json`.

Twelve source features have self-intersection or nested-shell validity issues. The matcher repairs those in memory with Shapely `make_valid`, retaining polygon components and unioning polygon components when the result is a geometry collection. The checked-in source geometry is unchanged. A geographic match is provisional until permitting authority is separately verified. |
| Fort McDowell Yavapai, Gila River, and Salt River | [U.S. Census Bureau TIGERweb, Federal American Indian Reservations](https://tigerweb.geo.census.gov/arcgis/rest/services/TIGERweb/AIANNHA/MapServer/2), January 1, 2026 vintage. | Census statistical geography is a locator, not proof of a parcel's permitting authority or a legal boundary determination. |
| Maricopa County unincorporated | No polygon cached. | A point outside the cached city and reservation layers is unresolved. The implementation does not infer county jurisdiction from absence and does not claim complete coverage of tribal, federal, or other exceptional lands. |

Matching uses an interior representative point from the supplied parcel geometry, with finite, in-range latitude/longitude as fallback. Boundary overlaps return all candidate IDs as `ambiguous`; missing or unmatched points stay unresolved. Overrides are reported as manual assignments with their own source marker. Since all registry rows remain draft, automatic and manual assignments remain provisional.

The public Maricopa County [city-limits guidance](https://www.hsd.maricopa.gov/696/City-Limits) says municipal boundaries are based on approved County annexation resolutions and are provided as a guide with no warranty. The cached statewide layer is useful for matching, but neither it nor the Census statistical boundaries establish verified AHJ status.
