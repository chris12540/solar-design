# Step 1 API contract

All endpoints use `/api`. Same-origin Vite proxy in development. API binds localhost. Authenticated staff session required for status, parcel lookup and runs. Login token stays server-side; do not embed credentials in frontend. Browser sends cookies. Validate mutation Origin when present; only configured UI/API origins allowed. Use HttpOnly SameSite session cookie. Production HTTPS/cookie configuration documented separately.

- `POST /api/session` body `{ "token": "..." }` -> `{ "user": "local-admin" }`; invalid token 401. `GET /api/session` -> same or 401. `DELETE /api/session` logs out.
- `GET /api/status` -> `{ "dataset": null | { "id": "...", "imported_at": "...", "snapshot_date": null, "input_rows": 1759897, "imported_rows": 1759895, "rejected_rows": 2, "files": [{"name":"...","sha256":"...","encoding":"cp1252","transform_version":2}] } }`. Counts shown are illustrative until import verifies them. Snapshot date null means unknown, never substitute file mtime.
- `GET /api/parcels/search?q=...` -> `{ "matches": [Parcel], "truncated": false }`. Minimum meaningful query length; bounded results (max 50); no implicit candidate confirmation. Indexed address search; alternate abbreviations normalized while retaining unit distinctions. No dataset -> 503; no matches -> 200 with empty list.
- `Parcel`: `{ "id": "04013:17707116", "apn": "17707116", "address": "7651 E VIA DE VENTURA", "unit": null, "city": "SCOTTSDALE", "postal_code": "85258", "year_built": 1980 | null, "mcr_key": "177705" | null, "mcr_name": "..." | null, "occupancy": "likely_owner_occupied" | "likely_not_owner_occupied" | "unknown", "occupancy_reason": "...", "dataset_id": "...", "source_file": "...", "source_row": 2, "latitude": null, "longitude": null }`. No owner or mailing-address values in browser/API responses. Preserve raw FolioKey as APN; four representative IDs, including a letter suffix, matched official county GIS records.
- `POST /api/runs`, `Idempotency-Key` UUID header, body `{ "name": "...", "original_address": "...", "parcel_id": "04013:..." | null, "selection": Selection }` -> 201 Run. Same key + same body -> same Run; same key + changed body -> 409. Creator from server session. Selected parcel copied to immutable run snapshot. Unknown parcel -> 422. `mcr` requires selected parcel with valid MCR. Radius/polygon can have no selected parcel.
- `Selection`: `{ "mode": "mcr" }`, `{ "mode": "radius", "center": { "lat": 33.4484, "lng": -112.074 }, "radius_meters": 500 }`, or `{ "mode": "polygon", "geometry": { "type": "Polygon", "coordinates": [[[lng,lat],...]] } }`. Radius >0 and <=10000m; polygon closed, simple, valid, max 500 vertices, max 100 square km; both restricted to configured Maricopa bounding extent as coarse validation ONLY. Exact county membership remains unverified until Step 2. UI must state that. No holes for MVP.
- `Run`: `{ "id": "uuid", "name": "...", "status": "draft", "created_at": "...", "created_by": "local-admin", "original_address": "...", "parcel": Parcel | null, "selection": Selection, "county_fips": "04013" }`. For MCR mode saved selection also includes resolved `mcr_key` and `mcr_name`, sourced from DB.
- `GET /api/runs/{id}` -> Run. Other creator/nonexistent ->404. No runs list endpoint in Step 1.
- Errors use FastAPI `detail` string or validation array; frontend turns these into readable text. All SQL parameters bound; no query interpolation.

Data importer: streaming CSV `delimiter='|'`, validate field count, reject missing/invalid parcel identifier but retain addressless parcels. Record rejected row reason/file/line without raw PII. Source filenames/hashes, encoding, transform version and optional snapshot date define dataset ID; promote atomically after full validation and indexing. Failed import leaves prior active dataset available. Re-import identical files is no-op; refresh published version only with new dataset. Avoid storing all 485MB in memory. Progress printed every 100k rows. Source data location supplied through CLI.

Development fallback map: Leaflet with OSM standard tiles, required visible attribution, no prefetch/bulk downloads; configurable tile URL/attribution. Manual center selection and polygon drawing work without geocoder. Defaults to Phoenix. Do not invent coordinates for matched parcel. Saved radius/polygon can be reviewed on same map. No Step 2 expansion, no designs.

Backend owns `backend/` only. UI owns `frontend/` only. Main owns infrastructure, scripts and docs. JSON contract is shared; report change proposals before modifying it.
