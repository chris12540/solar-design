# Map selection API contract

Implemented locally October 12, 2026. All endpoints authenticated using existing session cookie. Preserve legacy endpoints and existing saved runs. All geometry GeoJSON WGS84 Polygon/MultiPolygon (holes supported).

- `GET /api/neighborhoods/search?q=...` -> `{matches:[{mcr_key,mcr_name,parcel_count}],truncated:boolean}`; min 3 chars; bounded results. Search local recorded subdivision names; explicit candidates, never guess informal names.
- Existing `GET /api/parcels/search` retains existing response; add `property_type`, `puc`, `residential` (`true|false|null`) when available.
- `POST /api/areas/resolve` input one of `{kind:"subdivision",mcr_key}`, `{kind:"parcel",parcel_id}` (single-home only), `{kind:"address",parcel_id}` (subdivision if possible, single-home fallback), `{kind:"polygon",geometry,label?}`. Response `Area` below. Returns explicit 422 for excessive areas/geometry, 503 for unavailable GIS without cache. No fabricated map positions.
- `Area`: `{id:uuid,label,kind:"subdivision"|"parcel"|"polygon",mcr_key:null|string,boundary_source:"county"|"estimated"|"user_drawn"|"parcel",geometry:Geometry|null,original_geometry:Geometry|null,parcels:[MapParcel],unresolved_ids:string[],coverage:{mapped_count,unresolved_count,unknown_classification_count,complete:boolean,warnings:string[]},provenance:{dataset_id,gis_fetched_at, ...}}`.
- `MapParcel`: existing Parcel fields plus `geometry:Geometry|null`, `latitude:number|null`, `longitude:number|null`, `residential:true|false|null`. Only residential=true returned as selected parcels; unresolved known residential members remain with null geometry and clear coverage state. Parcel response must omit owner/mail.
- Area ID resolves to immutable server-side snapshot; server computes membership and provenance. Save must not trust browser-supplied parcel lists/counts. Persist snapshots in DB (not process memory), and permit same authenticated staff identity to access its resolved areas.
- `POST /api/runs` new body `{name,original_address?:string,selection:{mode:"areas",area_ids:string[],excluded_ids:string[],sample_ids:string[],intent:"single"|"sample"|"all"}}`; Idempotency-Key UUID unchanged. `single`/`sample` chosen IDs must belong to included residential group; single exactly one sample ID, sample >=1; all sample empty. Group membership is union of area parcels minus exclusions. Deduplicate county-qualified parcel IDs. Bound area/parcel counts; validate all exclusion/sample IDs. Original address optional for new mode.
- New Run retains legacy fields and adds `areas:Area[]`, `included_ids:string[]`, `excluded_ids:string[]`, `sample_ids:string[]`, `intent`, `coverage` (deduplicated known unresolved parcel count; unknown classification warning count may be per-area). Keep selected group and sample separate. Entire map snapshot immutable; edits create a new named draft, not silent mutation.
- `GET /api/runs` -> `{runs:[{id,name,created_at,status,parcel_count,intent}],truncated:boolean}` newest first, max50, creator scoped.
- `GET /api/runs/{id}` -> new Run above or old legacy Run. Old run explicitly shown as legacy reference; not falsely shown as resolved neighborhood.

UI: search candidates; choosing result resolves/outlines area and displays homes/count. Add areas rather than replace unless user clears. Remove area/remove home, restore home, sample home, single home. Draw polygon and edit boundary by vertex manipulation or redraw; editing resolves fresh working polygon, retains original source provenance in UI and saved area via optional `original_area_id` in polygon input (server verifies ownership). Fit map to geometry. Render holes/disconnected pieces. Recent runs. No designs/usage/filter controls in Step 1. Partial coverage warning visible in map and saved view.

Limits: first slice max 20 areas and 2,000 selected parcels per draft; reject oversized resolve explicitly rather than returning truncated area as complete. 10,000 geometry vertices, 100 km² user polygon bound, exact county spatial coverage where source available. Typical neighborhood target; citywide selection is Later.

Geometry membership uses PostGIS ST_Covers with ST_PointOnSurface. Estimated boundary union uses ST_UnaryUnion. County spatial-query manifests and geometries are persisted and reused; stale/offline cache warnings are explicit. Unresolved IDs include unmatched county APNs whose classification cannot be inferred. Editing preserves the source area ID and original geometry after ownership validation. Boundary redraw is supported; vertex drag editing is not.
